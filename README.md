# AI Cam

Живой робот-оператор в стиле **LOOI** для съёмки на iPhone + селфи-палка / DJI OM5.

## Возможности

- Лицо как у LOOI: два больших глаза, моргание, взгляд, реакция на касание
- Idle-поведение
- AI Director: портрет, кино, блог, предмет, пейзаж, спорт
- Камера: фото / видео, таймер, ручной режим
- Ориентация: подсказки портрет / альбом
- Мини-робот поверх камеры
- Быстрый запуск: Камера iOS, DJI Mimo, Фото
- Сценарии OM5
- PWA

## Открыть

`https://superyaroslav8-arch.github.io/AI-Cam/`

Settings → Pages → Deploy from branch `main` / root.

## Важно

Моторы OM5 из браузера недоступны — только подсказки и deep link в DJI Mimo.
